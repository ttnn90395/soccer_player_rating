This is a project that will try to predict the soccer transfer market in the next years.
Here is the roadmap : 
1) Create a model predicting the rating, potential and transfer value of a player from its career stats.
2) Analyze the tendencies of recent transfers to create a model predicting the next transfers.
3) Mix this with a model that predicts the scores of all matches
4) Also put into account the financial capacities of a team.

It is currently a huge mess but we're finishing the first step and we've already collected all the recent transfers for 2).
In terms of data, we need to get all the match scores of the last years, the length of the past contracts and get the financial capacity of a team.
In the end, we will probably have to guess the sponsors of each time in the future...
